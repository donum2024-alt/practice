# 경쟁사 벤치마킹 검토

## 상황

담당자가 특정 경쟁사를 조사 대상으로 정하면, 그 경쟁사의 SKU 수·물류 운영 방식·가격 책정 방식 등 잘하고 있는 부분을 자료로 모아 항목별로 정리하고, 우리가 벤치마킹할 지점을 뽑아 단계별 실행 전략까지 세운다. 최종 목적은 그 전략을 실제 사업에 반영해 물류비 절감이나 SKU 효율화를 통한 매출 증대 같은 성과를 내는 것이다.

## 등장인물

- **담당자** — 비전전략팀 기획 실무 책임자. 경쟁사를 정하고 자료를 모아 정리하고 벤치마킹 지점과 실행 전략을 수립한다.
- **회장님·경영진** — 조사할 경쟁사를 별도로 언급하기도 한다.
- **업계 지인** — 자료로 잘 드러나지 않는 정보를 물어볼 수 있는 사람들.
- **팀원** — 정보가 부족할 때 내부 회의에서 함께 논의한다.

## 오가는 것

- **조사 대상 경쟁사** — 담당자가 평소 눈여겨보던 회사, 또는 회장님·경영진이 언급한 회사.
- **수집 자료** — 경쟁사 홈페이지, 뉴스, 관련 기사에서 검색해 모은 내용.
- **경쟁사별 정리 문서** — SKU 수, 물류 운영 방식, 가격 책정 방식 등 항목별로 문서나 엑셀에 옮겨 적은 것. 경쟁사별 강점과 차별화 요소를 담는다.
- **벤치마킹 지점** — 정리 내용 중 우리가 따라 할 만하다고 뽑아낸 항목.
- **단계별 실행 전략** — 벤치마킹 지점을 실제로 실행하기 위한 프로세스와 단계별 방법.

## 흐름

1. 담당자가 조사할 경쟁사를 정한다 (평소 눈여겨보던 회사, 또는 회장님·경영진이 언급한 회사).
2. 담당자가 그 경쟁사의 홈페이지·뉴스·관련 기사를 검색해 자료를 모은다.
3. 담당자가 SKU 수, 물류 운영 방식, 가격 책정 방식 등 항목별로 문서나 엑셀에 정리한다.
4. 담당자가 경쟁사별 강점과 차별화 요소를 비교해 우리가 벤치마킹할 지점을 뽑아낸다.
5. 담당자가 그 지점을 실행할 구체적인 방법과 단계별 실행 전략(프로세스)을 수립한다.
6. 담당자가 그 전략을 실제 사업에 반영해 성과(물류비 절감, SKU 효율화를 통한 매출 증대 등)로 이어지게 한다.

## 예외

- 원하는 정보가 자료로 잘 안 나오는 경쟁사인 경우 → 담당자가 뉴스나 기사를 더 찾아본다. 그래도 부족하면 업계 지인에게 물어보거나, 정 안 되면 내부 회의에서 팀원들과 논의한다.

## 끝나는 지점

벤치마킹 지점마다 단계별 실행 전략이 붙고, 그 전략이 실제 사업에 반영되어 물류비 절감이나 매출 증대 같은 성과로 나타나면 이 업무가 완료된 것이다. (경영진 보고 자체는 목적이 아니다.)

## 지금의 불편함

- 자료 검색(2번)이 오래 걸린다.
- 항목별 정리(3번)가 오래 걸린다.
- 경쟁사별 물류 방식, SKU 운영 전략, 강점, 차별화 요소를 한눈에 비교해서 보고 싶은데 그렇게 정리하는 방식 자체가 오래 걸린다.

## 용어

| 용어 | 뜻 |
|---|---|
| 벤치마킹 검토 | 경쟁사가 잘하고 있는 부분을 분석해 우리가 어떤 부분을 벤치마킹하면 좋을지 검토하는 일 |
| SKU 수 | 경쟁사가 취급하는 상품 품목의 수 |
| 물류 운영 방식 | 경쟁사가 건설자재를 유통·배송하는 방식 |
| 가격 책정 방식 | 경쟁사가 가격을 매기는 방식 |
| 차별화 요소 | 경쟁사가 다른 곳과 구별되게 잘하는 점 |
| 단계별 실행 전략 | 벤치마킹 지점을 실제로 실행하기 위한 프로세스와 단계별 방법 |
