# ADR-0009 — AI 초안 생성(정리·전략)은 새로 검색하지 않고 이미 모인 자료만 입력으로 쓴다

## 맥락

항목별 정리 초안과 실행 전략 초안을 만드는 AI 기능이, 자료가 부족할 때 그 자리에서 추가로 웹을 검색하게 할지 정해야 했다. 자료 수집(`jaryo-suchip`)은 이미 별도의 웹 검색 기능으로 존재한다.

## 버린 대안

- **초안 생성 라우트에도 웹 검색 도구 권한을 부여해 부족한 자료를 그 자리에서 추가 검색** — 자료 수집 기능과 책임이 겹친다.

## 결과

`app/api/ai/draft-summary`와 `app/api/ai/draft-strategy`는 DB에 이미 저장된 `collected_materials`만 프롬프트에 넣고, 자체적으로 웹 검색을 수행하지 않는다. 두 기능의 책임 경계는 분명해지지만, 자료가 부족하면 담당자가 자료 수집 기능으로 돌아가 자료를 보강해야 한다.
