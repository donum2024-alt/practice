# ADR-0006 — AI가 찾은 자료도 수동 추가와 같은 엔드포인트로 저장한다

## 맥락

담당자가 AI 웹 검색 결과 중 선택한 항목과, 직접 찾은 자료를 모두 같은 수집 자료 목록에 쌓아야 한다.

## 버린 대안

- **AI 결과 저장 전용 엔드포인트(예: `/api/ai/collect-materials/save`)** — 검증 로직이 두 곳에 중복된다.

## 결과

AI가 제안한 자료를 담당자가 선택해 저장할 때도 `POST /api/competitors/[id]/materials`를 그대로 쓴다. 자료가 AI 출처인지는 `source_type` 값(`웹검색`)으로만 구분하며, 별도의 출처 플래그나 전용 응답 형태는 없다.
