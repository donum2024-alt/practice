# ADR-0007 — 정리 항목 키는 수집 자료의 분류 태그와 값을 공유한다

## 맥락

항목별 정리 화면에서 각 항목(SKU 수·물류·가격·강점·차별화 요소)을 채울 때, 같은 주제로 태그된 수집 자료를 옆에서 바로 보여줘야 한다.

## 버린 대안

- **독립된 `SummaryItemKey` enum을 따로 정의하고 자료의 `MaterialTopic`과 매핑 테이블/변환 함수로 연결** — 매칭 로직이 한 단계 더 생긴다.

## 결과

`SummaryItemKey`는 자료 태그 `MaterialTopic`(기타 제외)과 정확히 같은 문자열 값을 쓴다. 매칭은 값 비교만으로 끝나 단순하지만, 두 기능의 항목 구성이 강하게 결합되어 한쪽을 바꾸면 다른 쪽도 함께 영향을 받는다.
