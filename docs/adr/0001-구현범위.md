# ADR-0001 — 구현 범위

비전전략팀 담당자가 경쟁사를 조사 대상으로 정하면, AI가 자료 수집과 항목별 정리 초안을 도와 검색·정리 시간을 줄이고, 담당자는 그 결과를 검토·확정해 벤치마킹 지점과 단계별 실행 전략을 세운다.

## 커버리지

| 업무 단계 | 커버 | 남는 사람 몫 |
|---|---|---|
| 1. 조사 대상 경쟁사 결정 | 시스템 (등록·상태 관리) | 어떤 회사를 조사할지는 담당자가 직접 판단 |
| 2. 자료 수집 | 시스템 (AI 웹검색 + 수동 보완) | 지인·회의에서 얻은 정보는 담당자가 직접 텍스트로 옮겨 입력 |
| 3. 항목별 정리 | 시스템 (양식 + AI 초안) | 초안 검토·수정·확정은 담당자 책임 |
| 4. 벤치마킹 지점 도출 | 시스템 (기록 양식) | 어떤 지점을 따라 할지 판단은 담당자가 직접 |
| 5. 단계별 실행 전략 | 시스템 (양식 + AI 제안) | 전략의 타당성 판단과 다듬기는 담당자 |
| 6. 실제 사업 반영·성과 측정 | 없음 | 반영 여부·결과는 담당자가 메모로만 기록, 실제 반영 작업과 성과 측정은 도구 밖 |

## 해석에 영향을 주는 제외

- **실제 성과(물류비 절감, 매출 증대 등) 자동 계산·추적 없음** — 벤치마킹 지점의 결과 메모는 담당자가 적은 자유 텍스트일 뿐, 성과 수치를 시스템이 검증하지 않는다.
- **경영진 보고서 자동 생성·발송 없음** — 보고가 필요하면 담당자가 화면 내용을 보고 별도로 작성해야 한다.
- **자료 원본 파일 업로드·OCR·전체 페이지 크롤링 없음** — 수집 자료는 항상 요약된 텍스트 + 출처 링크일 뿐, 원본 문서나 페이지 전체가 보관되지 않는다.
- **실시간 경쟁사 모니터링·자동 알림 없음** — 자료는 담당자가 '자료 수집'을 다시 실행해야만 갱신되며, 경쟁사 소식 변화를 시스템이 스스로 알려주지 않는다.
- **AI 수집·초안의 자동 저장/확정 없음** — AI가 만든 모든 결과(수집 자료, 정리 초안, 실행 전략 초안)는 담당자가 선택하고 기존 저장 버튼을 눌러야만 실제로 반영된다.
- **사용자 인증·권한 분리 없음** — 담당자 1인 사용을 전제하며 접근 제어나 역할 구분이 없다.
- **웹 검색 외 유료 DB(신용정보 등) 미연동** — 자료 품질은 공개 웹 검색 결과 범위로 제한된다.
- **비교 결과 내보내기(엑셀/PDF)·저장된 비교 조합 관리 없음** — 비교는 화면에서 보는 동안만 유효하며 URL 공유 외의 보관 방법이 없다.
- **벤치마킹 지점 가중치·점수화·자동 순위 매기기 없음** — 어느 지점이 더 중요한지는 전적으로 담당자가 판단한다.
- **벤치마킹 지점·실행 단계의 담당자 배정·마감일 관리 없음** — 일정·책임 관리는 도구 밖에서 이뤄진다.
- **실행 단계별 완료 체크(세부 진행률) 없음** — 진행 상태는 벤치마킹 지점 단위(반영 상태)로만 표시된다.
- **여러 벤치마킹 지점의 실행 전략을 한 화면에 모아보는 뷰 없음** — 지점마다 펼쳐서 확인해야 한다.
- **경쟁사 카테고리/태그 분류 없음** — 필요하면 메모(note) 자유 텍스트로만 구분한다.

## 검증되지 않는 것

- **화면 표시·화면 간 이동** — 테스트 seam이 API route라 자동 검증되지 않는다. 서버가 무엇을 내려주는지는 테스트가 잠그지만, 그것을 화면에 어떻게 그리는지는 사람이 열어 확인한다.
