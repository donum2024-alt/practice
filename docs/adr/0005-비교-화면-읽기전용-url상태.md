# ADR-0005 — 비교 화면은 읽기 전용이며 선택 상태는 서버 대신 URL에 둔다

## 맥락

담당자가 여러 경쟁사의 정리 문서를 나란히 비교해 보고, 필요하면 조합을 공유하거나 새로고침 후에도 유지하고 싶어 한다.

## 버린 대안

- **비교 화면 전용 경쟁사 목록 엔드포인트** — 전체 경쟁사 목록·상태 조회는 기존 `GET /api/competitors`로 이미 충분하다.
- **선택한 비교 조합을 DB에 저장하는 '즐겨찾는 비교 조합' 기능** — 새 테이블/엔드포인트 없이 URL 공유로 같은 효과를 낼 수 있다.
- **비교 표에서 셀을 바로 편집하는 인라인 수정** — 정리 내용 수정 경로를 두 곳에 두면 어느 쪽이 최신인지 헷갈린다.

## 결과

경쟁사 선택 UI는 기존 competitors API를 재사용하고, `GET /api/summaries?competitorIds=...`는 조회만 제공한다(PATCH 없음). 선택된 조합은 URL 쿼리스트링에만 존재해 서버에 아무것도 저장하지 않으며, 정리 내용 수정은 항상 항목별 정리 화면에서만 이뤄진다.
