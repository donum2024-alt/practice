# ADR-0004 — 경쟁사 목록은 정렬 기준을 고정하고 구조화된 분류를 두지 않는다

## 맥락

담당자가 여러 경쟁사를 관리하면서 목록을 정렬하거나 분류해 보고 싶어 할 수 있다.

## 버린 대안

- **`sort` 쿼리 파라미터로 등록순/작업순을 선택하는 토글** — 담당자 1인이 소수의 경쟁사를 다루는 규모에서는 선택지가 생기는 이득보다 구현·UI 비용이 크다.
- **`category`/`tag` 컬럼과 그룹 필터 UI** — 구조화된 분류 비용이 현재 규모에 비해 과하다.

## 결과

목록은 항상 `updated_at DESC, id DESC`(최근 작업순)로만 정렬된다. 분류가 필요하면 `note` 자유 텍스트로만 표현할 수 있고, 구조화된 필터링은 지원하지 않는다.
