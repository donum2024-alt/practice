# ADR-0012 — 실행 전략이 생겨도 벤치마킹 지점의 반영 상태를 자동 전진시키지 않는다

## 맥락

경쟁사 상태는 자료·정리·벤치마킹 지점이 처음 생길 때 [[0003-상태-전진-분산-모노토닉]] 패턴으로 자동 전진한다. 벤치마킹 지점의 반영 상태(검토중/전략수립됨/사업반영됨/보류)에도 같은 패턴을 적용해, 실행 전략이 처음 추가될 때 '전략수립됨'으로 자동 전진시킬 수 있었다.

## 버린 대안

- **`strategy_steps`가 처음 추가될 때 반영 상태를 자동으로 '전략수립됨'으로 전진시키는 방식** — 경쟁사 상태와 달리 반영 상태는 담당자가 전적으로 관리하는 값으로 두기로 했다.

## 결과

반영 상태는 오직 담당자가 PATCH로 직접 바꿔야 하며, 순서 제약 없이 네 값 사이를 자유롭게 오간다. 실행 전략을 추가해도 반영 상태는 건드리지 않는다.
